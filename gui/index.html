Link and preflight

Preflight is read-only: it arms nothing and writes no parameter. Over the radio it must be GO within the last 10 minutes before a props-on run can be authorised. It checks the ground link, the right backpack, one relay, link loss and delay, the abort flag, and the aircraft's heartbeat.

Mission profiles

A profile is a saved offboard test: which aircraft, which link, how far through the flight to go, and the numbers the controller flies. Deleting archives to profiles/deleted/.
